# Data Extraction and Handling Rules

Last Updated: May 29, 2026

This document outlines how IzonLearner handles user data and complies with data extraction and deletion policies.

## 1. Data Collection
We minimize data collection to only what is necessary for app functionality, primarily:
*   Language learning progress (User ID, Lesson ID, Progress metrics).
*   User account profile data.

## 2. User Rights
Users have the right to:
*   **Request Data Access:** Obtain a copy of their learning progress and profile information.
*   **Request Data Deletion:** Delete their account and all associated data from our servers.

## 3. Data Processing
*   **Retention:** Data is retained as long as the account is active.
*   **Processing:** Data is processed securely on our servers. AI-related interactions are processed according to our Privacy Policy.
*   **Third-Party Sharing:** We do not sell user data. User data is only shared with service providers (e.g., hosting, AI APIs) strictly to provide the app's core functionality.
